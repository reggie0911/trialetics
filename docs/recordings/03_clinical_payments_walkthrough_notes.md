## Expected Outcome

### Main Page (`/protected/clinical-payments`)
- **Stats Cards** display:
  - Total Sites — count of sites with payment setup
  - Pending Activities — completed activities awaiting payment
  - Pending Records — payment records to be processed
  - Processed This Month — payments processed in current month
- **Sites Tab** — list of clinical sites with organization name, protocol number, and pending payment count badge
- **Payment Records Tab** — table of all payment records with status filters (pending, approved, processed, rejected), type filters, site/protocol columns
- **Protocol Summary Tab** — bar chart of Earned vs. Paid by protocol, with "Generate for [Protocol]" buttons

### Site Detail Page (`/protected/clinical-payments/sites/<siteId>`)
- Header: site number, protocol info, back button
- **Activities Tab** — payment activities linked to subject visits; columns: subject, visit, activity, amount, status
- **Exceptions Tab** — site-specific payment amount overrides for template activities
- **Records Tab** — payment records for this site
- **Sync Activities** button — creates payment_activities from completed subject_activities
- **Add Exception** dialog — override payment amount for a specific template activity
- **Add Unplanned Payment** dialog — create a one-off payment not tied to a template
- **Create Final Payment Record** — generate a consolidated payment record

## Key Records/States Generated by Demo Data

The seed migration (`20260208000000_seed_clinical_trials_data.sql`) creates:

| Entity | Count | Details |
|--------|-------|---------|
| Programs | 5 | Oncology, Cardiovascular, Rare Disease, Neurological, Autoimmune |
| Protocols | 12 | ONCO-001 through AUTO-003 |
| Regions | 6 | NA-1, NA-2, EU-1, EU-2, AP-1, LA-1 |
| Sites | Multiple | Across regions with site numbers |
| Subjects | Multiple | Enrolled subjects with visit schedules |
| Visit Templates | Multiple | With template visits and template activities (including payment amounts) |

The Clinical Payments module (`20260211000006_create_clinical_payments.sql`) adds tables:
- `payment_exceptions` — site-specific amount overrides
- `payment_activities` — generated from completed subject activities
- `payment_splits` — split payment allocations
- `payment_records` — final payment records with status workflow

## Troubleshooting Notes

| Issue | Resolution |
|-------|------------|
| Stats show all zeros | Payment activities are generated on-demand via "Sync Activities" on site detail; no seed data pre-populates `payment_activities` |
| Sites tab is empty | Ensure clinical sites exist; they are created by `20260208000000_seed_clinical_trials_data.sql`. Verify user's company matches the seeded company |
| "Sync Activities" produces no results | Subject activities must have `status = 'completed'` and belong to a site with template activities that have `payment_flag = true` |
| Exception dialog shows no activities | The site's protocol must have an active visit template with activities. Navigate to Visit Templates first to verify |
| Generate payment records shows 0 generated | There must be payment activities in "earned" status; sync activities first, then generate |
| Payment record status won't change | Check browser console for RLS errors; user must belong to the same company as the records |
